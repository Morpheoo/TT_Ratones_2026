================================================================================
                           FLUJO RECOMENDADO
================================================================================

PRIMERA VEZ (Setup inicial):
  1. python test_docker_setup.py        (Verificación completa - 1-2 min)
  2. launcher.bat                        (Abre la app si todo OK)

USO DIARIO (Cada sesión):
  1. python quick_diag.py               (Chequeo rápido - 10 seg)
  2. launcher.bat                        (Abre la app si todo OK)

SI ALGO FALLA:
  1. python quick_diag.py               (Identifica qué está mal)
  2. python test_docker_setup.py        (Debugging profundo - 1-2 min)
  3. Revisa TESTING_GUIDE.md            (Soluciones específicas)

================================================================================
                             POSIBLES RESULTADOS
================================================================================

✓ TODOS LOS TESTS PASAN:
  → ¡Excelente! Tu sistema está listo
  → Ejecuta: launcher.bat
  → Streamlit debería abrirse automáticamente

✗ UN TEST FALLA:
  → Revisa el mensaje de error
  → Busca la solución en TESTING_GUIDE.md
  → Ejecuta nuevamente el test después de arreglarlo

⚠️  VARIOS TESTS FALLAN:
  → Probablemente Docker no está abierto
  → Abre Docker Desktop
  → Espera a que esté listo (puede tardar 30-60 segundos)
  → Ejecuta nuevamente los tests

================================================================================
                         COMANDOS ÚTILES DE DOCKER
================================================================================

Ver estado de contenedores:
  docker ps -a

Ver logs en vivo:
  docker logs -f tt_ratones_db

Reiniciar servicios:
  docker-compose restart

Detener servicios:
  docker-compose down

Levantar servicios:
  docker-compose up -d

Entrar al contenedor:
  docker exec -it tt_ratones_db bash

Ver volúmenes:
  docker volume ls

Limpiar todo (CUIDADO - borra datos):
  docker-compose down -v
